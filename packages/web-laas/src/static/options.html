General

Changes apply to all tabs right away.

The browser left some shortcuts unassigned
Alt+Shift+K / Alt+Shift+L still work on ordinary pages (the page itself listens for them). Assign them in the browser to use them on pages like chrome:// too.

Editing

LaTeX preview

Floating preview while you type
While the caret is in math, the whole formula is rendered live: | marks where you are editing and □ a field still to fill. Esc hides it for now.

Cheat sheet

Snippet editor

Define snippets in text, like an Emacs config. Syntax

optionst text mode · m math mode · n inline math · M display math · A auto-expand (otherwise on Tab) · r string trigger is a regex · w not after a letter or digit · o needs an object to its left
$1 ${1:default}Tab stops; $0 is where the caret ends up; any other $ is a literal $
[[0]]the regex's first capture group
${PREV} ${PREV_INNER}the TeX object to the left (with o); INNER drops its outer () []
{ group, options, snippets: [...] }a group: its name shows in the cheat sheet, its options / sites pass to the snippets inside
sites / excludeSitesonly on / not on these sites (subdomains included)
description / previewthe cheat sheet's description, and the LaTeX it renders
priorityhigher wins; on a tie, the longer trigger wins

Shortcuts

Browser-level shortcuts are managed by Chrome and work on any page.

Global shortcuts

In an editor

Tab
In order: ① expand a Tab snippet ② inside a field, before its end → cdlatex movement (up to the field's end) ③ at a field's end → next field / leave the snippet ④ outside a snippet, in math → cdlatex movement
Tab
Shift+Tab
Tab in reverse: back through Tab's stops and the inside end of each group (\frac{x}{y}| → \frac{x}{y|} → \frac{x|}{y}); at a field's start → previous field; never out of the first field. Right after leaving $x$| it goes back in
ShiftTab
In math
Tab and Shift+Tab are always handled by web-laas, never moving focus to the page's buttons; in text right next to a formula they move into it

Sites

Auto-expand is off on these sites (subdomains included). The toolbar popup can also switch the current site with one click.

disabledSites in the config applies too; on Overleaf % starts a comment (latexCommentSites).

About

∑
web-laas

Emacs laas-style auto-expanding LaTeX snippets on the web. The engine is web-laas-engine.

Works in Overleaf and JupyterLab (CodeMirror 6), HackMD (CodeMirror 5), ChatGPT and Claude (ProseMirror), Notion (contenteditable), and ordinary text fields.
