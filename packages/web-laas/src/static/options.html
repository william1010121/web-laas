一般

行為設定會立即套用到所有分頁。

瀏覽器沒有指派部分快捷鍵
一般網頁上仍然可以用 Alt+Shift+K／Alt+Shift+L（由頁面內監聽處理）。到瀏覽器指派後，chrome:// 等頁面也能使用。

編輯行為

Snippet 組合

laas 預設 laas.el
逐條移植自 Emacs laas.el（ 個）。可在 Snippet 編輯器用 useDefaults: false 關閉

LaTeX 預覽

打字時浮動預覽公式
游標在數學式裡時，即時渲染整條公式，| 標出你正在改的位置、□ 是還沒填的欄位；按 Esc 暫時隱藏。

Cheat sheet

Snippet 編輯器

像 Emacs 設定檔一樣用文字定義 snippet。語法說明

optionst 文字模式 · m 數學模式 · n 行內數學 · M 區塊數學 · A 自動展開（否則按 Tab） · r 字串 trigger 當 regex · w 前面不能是英數字 · o 需要左邊有物件
$1 ${1:預設}Tab 跳位；$0 是最後游標位置；其他的 $ 都是字面上的 $
[[0]]regex 第一個括號群組
${PREV} ${PREV_INNER}左邊的 TeX 物件（搭配 o）；INNER 會去掉外層 () []
{ group, options, snippets: [...] }群組：名稱顯示在 cheat sheet，options／sites 會傳給裡面的 snippet
sites / excludeSites只在／不在某些網站生效（含子網域）
description / previewcheat sheet 上的說明，以及要渲染的 LaTeX
priority數字越大越優先；同優先權時 trigger 越長越優先
試玩區
使用編輯中的設定。試試 mk x/ ;a xii 再按 Tab
在任何網頁按 Alt+Shift+K 也能叫出這份表（只列該網站可用的 snippet）

快捷鍵

瀏覽器層級的快捷鍵由 Chrome 管理，可以在任何網頁使用。

全域快捷鍵

在編輯器裡

Tab
依序：① 展開 Tab 型 snippet ② 欄位裡還沒到結尾 → cdlatex 移動（最多到欄位結尾）③ 欄位結尾 → 下一格／離開 snippet ④ 不在 snippet、在數學模式 → cdlatex 移動
Tab
Shift+Tab
Tab 的反方向：往回停在 Tab 的停靠點和「群組結尾內側」（\frac{x}{y}| → \frac{x}{y|} → \frac{x|}{y}）；欄位開頭 → 上一格；第一格不會跳出。剛跳出 $x$| 時會回到裡面
ShiftTab
在數學式裡
Tab 與 Shift+Tab 一律由 web-laas 處理，不會跳到網頁上的其他按鈕；在文字裡緊鄰公式時也會跳進公式
Tab
取消剛剛的展開
展開後立刻按
Backspace

網站

在這些網站停用自動展開（含子網域）。也可以在工具列 popup 一鍵切換目前網站。

設定檔中的 disabledSites 也會生效；Overleaf 會把 % 視為註解（latexCommentSites）。

關於

∑
web-laas

在網頁上使用 Emacs laas 風格的 LaTeX 自動展開 snippet。引擎為 web-laas-engine。

支援 Overleaf、JupyterLab（CodeMirror 6）、HackMD（CodeMirror 5）、ChatGPT／Claude（ProseMirror）、Notion（contenteditable）以及一般輸入框。
