Features
Write math as fast as you think it.

  
Every animation below is recorded keystroke by keystroke from the real engine: nothing is mocked up.




  

    01
laas snippets, auto-expanding

    
Inside math, short keys expand the moment you type them: ;a → \alpha, sr → ^2, <= → \leq, x1 → x_1, iff → \iff. Outside math nothing happens, so ordinary writing is never touched.

    
Press Backspace right after an expansion to get back what you typed.

    02
Fractions that take what's to their left

    
/ turns the object before it into a numerator: x_1/ → \frac{x_1}{}, and (a+b)/ drops the parentheses → \frac{a+b}{}. // makes an empty fraction to fill in.

    03
cdlatex, too

    
Backtick symbols (`a → \alpha, `` for the second level), quote modifiers on the last character (x'. → \dot{x}, v'b → \mathbf{v}), _ → _{}, Tab commands like frTab and sqTab, and $ [ { pairing.

    04
Tab that knows LaTeX

    
Snippets have fields, like yasnippet: Tab moves to the next one, and after the last it leaves the snippet. Outside a snippet, Tab moves like cdlatex-tab: out of a group, into the next empty {}, past the closing $. Shift+Tab goes back.

    05
A live preview while you type

    
While the caret is in math, a small card renders the whole formula, marks where you are with a caret and shows the fields still to fill as □. It sits above the caret (or below, or in the corner) and Esc hides it.

  

  





  

    06
Formulas rendered in place

    
Once the caret leaves a formula, it's drawn typeset right over its source, as crisp SVG. Move the caret back in (or click it) and the LaTeX is there to edit. It keeps up with long documents: only the formulas near the window are drawn.

Make it yours
Your own snippets, your sites.




  

    07
Write your own snippets

    
The options page has a small config language: a JavaScript object with triggers, replacements, fields, regex triggers and per-site rules. Errors are shown as you type, and a test box tries the config before you save it.

  

  
// My snippets
{
  snippets: [
    { trigger: "EE", replacement: `\mathbb{E}`, options: "mA" },
    { trigger: /([a-zA-Z])tld/, replacement: `\tilde{[[0]]}`, options: "mA" },
    { trigger: "beg", replacement: `\begin{$1}
	$0
\end{$1}`, options: "tA", sites: ["overleaf.com"] },
  ],
  disabledSites: ["mail.google.com"],
}






  

    08
Per-site control

    
Turn web-laas off for a site from the toolbar, and choose what mk and dm insert there: $…$ or \(…\) inline; $$, \[ \], equation* or align* for display math.

Privacy & permissions

  
web-laas runs entirely in your browser. It collects no data, makes no network requests of its own, has no analytics and loads no remote code. Your settings stay in the browser's extension storage. Privacy policy.

  

    
PermissionWhy

    
storageYour settings: on/off, sites you turned it off on, per-site delimiters, preview options and your own snippets.

    
scriptingLoads the preview and cheat sheet into a page only when they're needed, and brings tabs that were already open up to date after an install or update.

    
notificationsShortcut feedback on pages where the in-page message can't show, such as chrome:// pages.

    
Access to all sitesSnippets have to work in whatever editor you write math in, so the content script runs on every site. Nothing on the page leaves your browser.

  






  
Know the limits

  
    
    
  • Pages that block extensions (chrome:// pages, the Chrome Web Store, the PDF viewer) can't be scripted.
    • 
    
  • Formulas drawn in place cover their source; an editor that is rotated, faded or clipped by its page keeps showing the source instead.
    • 
    
  • Your snippet config is passed to the pages you use web-laas on, because the snippets run there.
